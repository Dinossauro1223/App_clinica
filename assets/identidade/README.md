# Identidade visual NutriLab

Reconstrução gráfica inspirada na tela de boas-vindas original, autorizada para uso no projeto.

- `nutrilab_identidade.svg`: composição completa com grupos nomeados.
- `componentes/`: arco, folhas, maçã, DNA, frasco, wordmark, assinaturas e folha da marca em arquivos separados.

Grupos principais: `topo-temas`, `boas-vindas`, `wordmark`, `subtitulo`, `linha-verde`, `facisa-ufrn`, `simbolo-cientifico`, `arco`, `folhas`, `maca`, `dna`, `frasco` e `decoracao-inferior`. No componente de folhas, cada uma tem ID próprio para animação independente.

É uma reconstrução aproximada, não vetorização fiel do PNG. Textos dependem de Arial/Helvetica; assinatura institucional é aproximada e deve ser substituída por ativo oficial quando disponível. O PNG original `welcome_nutrilab.png` permanece preservado.
